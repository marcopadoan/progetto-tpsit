# ASH R6: Fuga da Kabul EFN

2D Top-Down Shooter, incentrato sulla fuga di Ash e il percorso difficile per arrivarci

## Avvio

Per avviare il gioco, eseguire su Windows:
```
pip install -r requirements.txt
python src/game.py
```
e su Linux/Mac:
```
pip install -r requirements.txt
python3 src/game.py
```
